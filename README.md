# Eq_Nexum_Proyecto

Proyecto base para la implementación del caso **Gestión_Ventas_PaquetesTurísticos** usando Java (Ant) y patrón MVC.

## Estructura inicial
```
Eq_Nexum_Proyecto/
├─ build.xml
├─ src/
│  ├─ controlador/
│  │  └─ Main.java
│  ├─ modelo/
│  │  └─ .gitkeep
│  └─ vista/
│     └─ .gitkeep
└─ .gitignore
```

## Cómo compilar y ejecutar (Ant)
```bash
ant run
```

> El punto de entrada actual es `controlador.Main`, que abre una ventana básica (JFrame).
